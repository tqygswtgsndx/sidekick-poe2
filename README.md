## Overview

Sidekick is an open-source in-game overlay for Path of Exile 2 that provides real-time item price checking against the PoE trade API, build comparison tooltips, divine orb value calculations, quick map tier lookup, and crafting outcome probability display — all accessible without leaving the game.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sidekick** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Price Check** | Real-time item price lookup against the official PoE trade API |
| **Item Comparison** | Compare hovered items to equipped gear with profit/loss indication |
| **Currency Rates** | Live exchange rates for all Path of Exile 2 currency items |
| **Crafting Odds** | Displays probability outcomes for crafting currency applications |
